# 使用手册

当前版本：`0.2.1`。

## 1. 界面布局

深色侧边栏从上到下分为：

| 区域 | 说明 |
|---|---|
| 顶部标题栏 | 工程路径 + 刷新按钮 |
| 模型配置面板 | 模型下拉、API Key 输入、上传特征开关 |
| 原理图摘要卡片 | 符号数、连线数、标签数、版本 |
| 聊天记录区 | 独立滚动，输入区不会被滚走 |
| 工具按钮栏 | 特征、ERC、解释、SPICE、快照 |
| 搜索栏 | 符号/封装关键词搜索 |
| 可执行计划面板 | 显示计划 JSON、预览、执行并校验 |
| 底部输入区 | Enter 发送，Shift+Enter 换行 |

## 2. 模型配置

侧边栏顶部的模型配置区：

1. **模型选择**：下拉菜单可选 DeepSeek V4 Pro 或 DeepSeek V4 Flash。
2. **API Key**：输入 DeepSeek API Key，点击“保存”。
3. **随对话上传原理图特征**：开启后，每次对话会附带当前工程的紧凑特征 JSON。

保存后状态会持久化到本地。未配置 API Key 时使用最基础的本地 mock 模式，不调用外部模型。

## 3. 工程识别

Agent 启动后会自动读取工程和原理图：

- 从 PCB Editor 插件启动时，优先使用插件传入的工程路径。
- 从桌面快捷方式启动时，优先识别 KiCad Schematic Editor 最近打开的原理图，并映射到同名工程。
- 如果无法识别，则回退到上一次使用的工程或样例工程。

顶部摘要会显示符号、连线、标签和 KiCad schematic version。

## 4. 从空工程生成简单电路

在空工程中可以输入：

```text
请生成一个1kHz方波转三角波的滤波电路
```

Agent 会生成 `schematic.generate_circuit` 计划。确认执行后会：

1. 如有必要，创建最小 `.kicad_sch` 文件。
2. 放置输入/输出标签、R/C 元件和 GND。
3. 自动生成连线、junction 和说明文本。
4. 创建快照。
5. 写入 `.kicad_sch`。
6. 运行 ERC 和 netlist 导出校验。

当前还支持类似请求：

```text
请生成一个简单积分电路
请搭建一个RC微分电路
```

## 5. 修改元件参数

输入自然语言：

```text
把 R4 改成 2K
```

Agent 会显示 Thinking 提示、生成可执行计划，并允许预览 diff。点击“执行并校验”后，会创建快照、写入 `.kicad_sch` 并运行 ERC/netlist。

## 6. 新增元件

输入例如：

```text
帮我新增一个 10K 电阻 R100
```

Agent 可能返回 Markdown 表格或直接生成计划。确认执行后：

- 自动跳过已存在 Reference。
- 追加 symbol 实例到原理图末尾。
- 执行前创建快照。
- 执行后运行 ERC + netlist 校验。

## 7. 上下文确认执行

如果上一轮 Agent 给出了可执行计划，可以直接回复：

```text
执行
```

或 `ok`、`yes`、`直接帮我执行`。前端和后端都会识别确认意图，并执行上一条计划。

## 8. ERC + Netlist

点击 **ERC**：运行 KiCad ERC 并显示违规数量。

点击 **解释**：分组整理违规类型，给出常见修复建议。

## 9. SPICE 导出

点击 **SPICE**：调用 `kicad-cli sch export netlist --format spice`，导出 `.cir` 文件。

## 10. 符号和封装搜索

在搜索框输入关键词（如 `Device`、`SOT-23`），点击“符号”或“封装”，即可搜索 KiCad 默认库目录。

## 11. 原理图特征

点击 **特征** 查看当前上传给模型的工程上下文 JSON，包括元件族分布、高频 value、电源符号、有源器件列表和元件列表。

## 12. 快照

点击 **快照** 查看最近 8 条快照记录。每次写入前系统会自动创建快照。
