# 使用手册

## 1. 界面布局

深色侧边栏从上到下分为：

| 区域 | 说明 |
|---|---|
| 顶部标题栏 | 工程路径 + 刷新按钮 |
| 模型配置面板 | 模型下拉、API Key 输入、上传特征开关 |
| 原理图摘要卡片 | 符号数、连线数、标签数、版本 |
| 聊天记录区 | 独立滚动，输入区不会被滚走 |
| 工具按钮栏 | 特征、ERC、解释、SPICE、快照 |
| 搜索栏 | 符号/封装关键词搜索 |
| 可执行计划面板 | 显示计划 JSON、预览、执行并校验 |
| 底部输入区 | Enter 发送，Shift+Enter 换行 |

## 2. 模型配置

侧边栏顶部的模型配置区：

1. **模型选择**：下拉菜单可选 DeepSeek V4 Pro 或 DeepSeek V4 Flash
2. **API Key**：输入 DeepSeek API Key，点击「保存」
3. **随对话上传原理图特征**：开启后，每次对话会附带当前工程的紧凑特征 JSON（元件族分布、有源器件、电源符号等）

保存后状态会持久化到本地。未配置 API Key 时使用本地 mock 模式。

## 3. 工程摘要

启动后自动读取原理图，顶部卡片显示：

- 符号数量
- 连线数量
- 标签数量
- KiCad schematic version

## 4. 修改元件参数

输入自然语言：

```text
把 R4 改成 2K
```

Agent 会：
1. 显示「[模型名] Thinking...」旋转提示
2. 生成可执行计划（包含 old_value / new_value 对比）
3. 计划面板显示详细 JSON

点击 **预览** 查看 diff。

点击 **执行并校验**，Agent 会依次：
1. 创建快照
2. 修改 `.kicad_sch`
3. 运行 ERC
4. 导出 netlist
5. 显示校验结果

## 5. 新增元件

输入例如：

```text
帮我新增一个 10K 电阻 R100
```

Agent 可能会返回 Markdown 表格：

```text
| 参考位 | 值 | 封装 | 符号库 |
| R100   | 10K |     | Device:R |
```

或直接生成计划。确认执行后：
- 自动跳过已存在的 Reference
- 追加 symbol 实例到原理图末尾
- 执行前创建快照
- 执行后运行 ERC + netlist 校验

> 当前新增元件只追加符号实例，不自动连线和布局。请在 KiCad 中手动调整。

## 6. 上下文确认执行

如果上一步 Agent 给出了可执行计划，你可以直接回复：

```text
执行
```

或 `ok`、`yes`、`直接帮我执行` 等。Agent 会识别确认语并直接执行上一条计划。

前端也会识别确认语，在发送时直接触发执行而非发起新对话。

## 7. ERC + Netlist

点击 **ERC**：运行 KiCad ERC 并显示违规数量。

点击 **解释**：分组整理违规类型，给出常见修复建议。例如：

```text
Input Power pin not driven by any Output Power pins
建议：检查电源输入脚是否由电源输出脚或 PWR_FLAG 驱动。
```

## 8. SPICE 导出

点击 **SPICE**：调用 `kicad-cli sch export netlist --format spice`，导出 `.cir` 文件。

## 9. 符号和封装搜索

在搜索框输入关键词（如 `Device`、`SOT-23`），点击「符号」或「封装」：

- 搜索 KiCad 默认库目录
- 返回匹配的库文件名称和路径

## 10. 原理图特征

点击 **特征** 查看当前上传给模型的工程上下文 JSON，包括：

- 元件族分布（R / C / U / Q / ...）
- 高频 value
- 电源符号
- 有源器件列表
- 元件列表（默认最多 120 个）

## 11. 快照

点击 **快照** 查看最近 8 条快照记录，包括：

- 创建时间
- 修改原因
- 源文件和快照文件路径

每次写入前系统自动创建快照。后端已有恢复接口。
